# Lab Activity 1 - Software Design Laboratory

- This project is based on the CPE106L-4 Grading System.
- Input your grade and the program will provide the apropriate equivalent
- AI Disclosure: There were use of AI Assisted tools 

## Project Structure
- `src/main.py`: Contains the core grading evaluation logic based on the Mapúa grading table.
- `tests/test_cases.py`: Script executing 3 distinct test cases verifying the grading scale logic.

## Execution Instructions
1. Activate virtual environment:
   `source venv/bin/activate`
2. Run main script:
   `python3 src/main.py`
3. Run test cases:
   `python3 tests/test_cases.py`
